
# unict-solab - Sistemi Operativi (Laboratorio) DMI UNICT 2023 -> 2026


## About

This repository contains my solutions to the past laboratory exams of the teaching "Sistemi Operativi" held in Unict DMI.

This repository is not to be intended as a substitute or base study material to pass the exam.

Some parts of code are implemented in my C code collection [saelib](https://github.com/Saendhor/saelib)

## Getting Started

**Directory Structure**

Each directory contains:
- Original ".pdf" file given by the professor with the assignment;
- "README.MD" file with the text from the relative pdf file formatted to be seen in webview;
- "run.sh" script in bash so that you can directly compile and execute the code;
- ".c" file containing the code.
